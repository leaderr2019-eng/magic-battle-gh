# Heroes of Astoria — Magic Battle

Билд для GitHub Pages / Пикабу Игры.

## URL после публикации

`https://YOUR_USER.github.io/REPO_NAME/`

## GitHub Pages

1. Settings → Pages → Deploy from branch → `main` → `/ (root)`
2. Подождите 1–2 минуты

## Пикабу Студия

В карточке игры укажите этот URL как «Ссылка на игру» и в разделе «Тестирование».
